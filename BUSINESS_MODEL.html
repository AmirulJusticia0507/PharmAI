# PharmAI Business Model — Premium & B2B Integration Scenarios ## 1. Premium Model ### Tiered Subscription | Tier | Target | Price | Features | |---|---|---|---| | **Free** | Personal users | Rp 0/bulan | 10 scans/bulan, basic drug DB, simple interaction check | | **Pro** | Pharmacists, medical students | Rp 49.000/bulan | Unlimited scans, batch drug analysis, advanced interaction, OCR, export PDF, drug catalog analytics | | **Pharmacy** | Apotek owners | Rp 299.000/bulan | Multi-user (5 staff), patient history tracking, e-resep integration, inventory sync, white-label reports | | **Enterprise** | Hospitals, healthtech, pharma | Custom | Full API access, custom AI models, SLA 99.9%, dedicated support, on-premise deployment | ### Premium Feature Breakdown #### A. Enhanced AI Accuracy - **Multi-model ensemble**: Combine GPT-4o-mini + Claude 3 + specialized RxNorm model - **Custom fine-tuning**: Fine-tune on Indonesian drug data (BPOM-specific terminology) - **Confidence threshold**: Block low-confidence (<70%) results, flag for human review #### B. Batch Processing & Automation - **Auto-analysis mode**: Agent processes entire drug catalog overnight - **Bulk import**: Upload CSV of patient medications → auto-check interactions - **Scheduled reports**: Daily/weekly interaction reports sent to email/portal #### C. Advanced Analytics - **Drug utilization analytics**: Top prescribed drugs, seasonal trends - **Interaction network graph**: Visualize drug interaction relationships - **Patient risk scoring**: Aggregate interaction risks per patient - **Inventory optimization**: Recommend stock levels based on prescription trends #### D. API Access (B2B) - **RESTful API**: `/v1/drugs`, `/v1/scan`, `/v1/interactions`, `/v1/analyze` - **Webhooks**: Real-time notifications for critical interactions - **Rate limiting tiers**: 1K/10K/100K calls per month - **SLA guarantees**: 99.9% uptime, <500ms response time ## 2. B2B Integration Scenarios ### A. Apotek (Retail Pharmacy) Integration **Use Case:** Apotek wants to automatically verify drug interactions when dispensing. ``` Apotek POS System │ ├── Scan patient insurance card ├── Scan prescription (physical or e-resep) ├── [API CALL] POST /v1/interactions │ Payload: {"drugs": ["PARACETAMOL", "TRAMADOL", "IBUPROFEN"]} ├── Response: {"severity": "high", "actions": ["warn", "contact_doctor"]} └── Pharmacist reviews flagged interactions before dispensing ``` **Integration methods:** 1. **API integration** — Apotek's system calls PharmAI API 2. **Web widget** — Embeddable iframe pharmacists use in-browser 3. **Mobile SDK** — APK wrapper for apothecary mobile apps ### B. EHR/EMR (Electronic Health Records) Integration **Use Case:** Hospital EHR wants to auto-flag dangerous drug combinations at order entry. ``` Doctor Orders New Prescription │ ├── EHR submits drug list to PharmAI ├── POST /v1/patient-interactions │ Payload: { │ "patient_id": "P-12345", │ "current_drugs": [...], │ "new_drug": "WARFARIN", │ "diagnoses": ["atrial fibrillation", "hypertension"] │ } ├── AI returns: {"risk_level": "critical", "interactions": [...], "contraindications": [...]} └── EHR blocks order + alerts doctor ``` **Value:** Reduce adverse drug events (ADEs) by 40-60% in pilot studies. ### C. HealthTech Platform Integration (Halodoc, Alodokter, Prainusa) **Use Case:** Health tech platform wants to add AI-powered drug info to their app. ``` User Scans Physical Pill │ ├── Health app sends image to PharmAI /v1/scan-pill ├── AI identifies: "METFORMIN 500mg" ├── Auto-call /v1/analyze-drug for usage guidance ├── Auto-call /v1/drug-info for side effects & interactions ├── Health app shows: │ - Drug name + dosage │ - Indication (diabetes T2) │ - Usage instructions │ - Interaction warnings │ - Nearby apotek with stock └── Option: Book appointment with doctor if concerning ``` ### D. Pharma Company Integration **Use Case:** Pharma wants to verify drug data accuracy and monitor post-market safety. ``` Pharma Safety Team │ ├── Monthly batch upload: new drug variants / formulations ├── POST /v1/batch-verify │ - Verify drug info against BPOM database │ - Cross-check with international pharmacopeia │ - Flag data discrepancies └── Receive report: { "verified": 95%, "discrepancies": [...], "missing_fields": [...] } ``` ## 3. Partnership Scenarios ### A. BPOM (Badan Pengawas Obat dan Makanan) Partnership **Scenario:** Official drug data provider - **Licensing**: BPOM provides official drug registry API → PharmAI gets verified data - **Reciprocal**: PharmAI feeds back AI-analyzed usage data to BPOM - **Revenue**: Government contract for drug info platform ### B. Apotek Chain Partnership (Kimia Farma, Guardian, Watson) **Scenario:** In-store pharmacist tool - **Deployment**: Pharmacist tablet/kiosk with PharmAI Pro - **Workflow**: Customer asks about drug → pharmacist scans → AI provides info - **Revenue**: Per-apotek subscription (Rp 299K–999K/bulan) + usage-based fee ### C. Hospital Network Partnership **Scenario:** Clinical decision support system - **Deployment**: Integrate into hospital HIS (including government hospitals) - **Workflow**: Doctor prescribes → AI checks interactions → auto-alert - **Revenue**: Per-hospital license (Rp 5M–50M/year) + implementation fee ### D. Insurance / BPJS Partnership **Scenario:** Prevent adverse drug events to reduce claims - **Workflow**: BPJS member gets prescription → check interactions → prevent ADEs - **Metric**: Track ADE-related claim reduction (20-30% savings) - **Revenue**: Performance-based (share savings) or fixed per-member fee ### E. Medical School / University Partnership **Scenario:** Educational tool for pharmacy students - **Features**: Drug quiz, case studies, interaction scenarios - **Revenue**: Annual campus license (Rp 50M–100M/year per university) - **Lead gen**: Students become future Pharmacist customers ## 4. Technical Implementation Requirements ### API Gateway & Security - **API Gateway** (AWS API Gateway / Kong): Rate limiting, auth, logging - **OAuth 2.0**: Client credential flow for B2B - **Webhook signing**: HMAC validation for webhook endpoints - **Data encryption**: At-rest (AES-256) + in-transit (TLS 1.3) ### Scalability for B2B - **Worker queues**: Celery + Redis for batch processing - **Load balancing**: Auto-scale based on request volume - **Caching**: Redis cache for frequent drug lookups (90% cache hit rate) - **Multi-region**: Deploy closer to customers (SGD, Jakarta) ### Compliance - **ISO 13485**: Medical device quality management - **GDPR/Bill POBI-like**: Data protection (if handling patient data) - **BPOM compliance**: Drug info accuracy requirements ## 5.
